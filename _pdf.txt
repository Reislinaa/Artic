07 EMI 的建议
BRAND COLOR STRATEGY · DESIGN SCOPE · BRAND GUIDELINES
一、品牌色彩策略
1. 基础品牌色：黑与白。黑白两色作为品牌的基础色，在界面中占据绝对主导的大面积使用。公司及产
品标识系统均为黑白 —— 若官网或软件界面中其他颜色过多，将稀释品牌识别度，与标识系统无法自洽
。因此黑白之外的第三种颜色一律小面积、点缀式使用，仅作为视觉记忆点出现。
2. 点缀色：橙色（首选）。本产品服务于日常与工作中表达密度较高的人群，目标是帮助他们更大胆、
更快速地表达，提升表达效率，使表达天赋得到充分发挥。清晰、结构化的自我表达，会让他人感受到 c
harismatic（有魅力的）、luminant（发光的）、enlightened（开悟通透的）、inspiring（鼓舞人心的）
等特质 —— 这些气质与橙色的能量感、温度感与创造力高度契合，绿色与黄色则次之。
3. 橙色选用细节：色相偏黄、明度偏高，避免偏红（太橘）或偏暗；可采用橙色渐变或光晕形式呈现（
参考 01 / 02 节的深色底橙色光晕）。点缀色在单个界面中的占比建议控制在 5%–10% 以内，仅用于关
键行动按钮、核心数据高亮与品牌记忆点，不大面积铺色。
二、设计需求与品牌规范
1. 当前设计需求范围：官网 UI 设计，以及 Windows 与 macOS 客户端软件的 UI 设计。
2. 品牌 UI 语言体系：需要建立一套统一、可延展的品牌 UI 语言规范（涵盖色彩体系、字体系统、圆角
与间距、光效/渐变语言、留白节奏与版式栅格）。该规范需具备跨媒介延展性 —— 后续海报、周边 T 
恤等线下物料均沿用同一套视觉语言，确保品牌在所有触点的一致性。
附注：Logo 方向
当前 logo 方向稿（见 03 节）与品牌名「万物本相」的语义关联度不足，图形概念需要重新推敲；同时
橙色占比偏大，与点缀色原则不符，建议缩小橙色面积或改为渐变光形式。
